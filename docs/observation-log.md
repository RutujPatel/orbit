# Shadow ORBIT Observation Log

## Purpose

This is the standard research record for each real Shadow ORBIT review.

It is an experimental artifact, not a specification for a customer-facing feature.

Create one completed copy per review.

When information is unavailable, record one of:

- not_observed
- not_asked
- participant_declined
- not_applicable

Do not leave ambiguous blanks.
